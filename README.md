# websiteTQA

Marketing site for [The Quiet Achiever](https://www.thequietachievr.com) — homepage, book, speaking, Toni, etc.

The **design system** and **visual library** (674 Tailwind blocks, component catalog, previews) live in the separate [`designsystem`](https://github.com/timyeothequietachievr/designsystem) repo, deployed at [designsystem-weld-six.vercel.app](https://designsystem-weld-six.vercel.app). Old `/design-system` and `/visual-library` URLs on this site redirect there.

Built with [Next.js](https://nextjs.org).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub, then import this repo on [Vercel](https://vercel.com/new) for production hosting and a custom domain later.
